# Writing, self-check and independent review

The author writes the article and its internal links, saves a candidate, performs a fresh-context self-check, addresses the feedback and delivers. An independent Reviewer evaluates the exact delivered version. Requested revisions return to the same author Task/Run; existing owner publication approval remains required.

The editor coordinates assignments and reviews without inspecting child internal conversations. Source snapshots, claim ledgers, coverage plans, candidate artifacts and review receipts provide the attributable handoff.

## Domain tools and decisions

- Link discovery exposes actual published articles, eligible peer articles and configured product-page targets, with locale and stable references. A configured URL is not proof that its page was fetched or its product claims verified.
- Draft saving protects candidate identity, body structure, scoped references, evidence locations and the active persisted content contract. Fresh self-check findings return to the author for judgment and revision.
- Delivery identifies the saved candidate and the handling of feedback. Review uses that candidate rather than silently choosing the latest editable draft.
- Revision receives the actual prior candidate, review findings and permitted evidence references. Published data and accepted old versions are not edited through a draft operation.

Reader value, evidence sufficiency, suitable link placement, whether revision is useful and when to defer remain Agent judgments. Any content-contract limits must be declared by the domain contract; they are not universal search-engine rules. The shared renderer reports real format and URL capabilities through [article presentation contracts](gsc-technical-checkpoints.md).

## Integrity and evaluation

Mechanical validation protects workspace/site/locale scope, exact source quotes, actual candidate locations, observed versions, replay, cancellation and publication approval. Successful work survives unrelated failures. Errors identify the affected reference and field so the same Agent can repair a draft without discarding valid content.

Evaluate a complete real-model path with a dedicated test site: writing, self-check, independent review, any requested revision, owner approval and publication. Read back the final stored version and rendered article; a model saying it passed is insufficient. Keep account identifiers, raw conversations and operational receipts outside public documentation.
